一个接口建一条短链，一把密钥接进任意系统。
每个请求都能直接在本页试。

接口约定

全部返回 JSON
  • Base URL{{ request.base_url }}api
  • 鉴权X-Api-Key: sk-xxxx站点开启「要求 API 密钥」后必带；查链接库与统计始终要管理员会话
  • CSRFX-CSRF-Token本站页面内的写请求会自动带上；脚本调用不受限
  • 错误{"ok": false, "message": "原因"}HTTP 状态码同步给出 400/401/403/409/422/429

创建短链接

POST /api/links 
curl -X POST {{ request.base_url }}api/links \
  -H 'Content-Type: application/json' \
  -H 'X-Api-Key: sk-...' \
  -d '{"target":"https://example.com/a/very/long/link"}'
